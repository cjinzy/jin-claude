# jin-range

평소라면 비싸서 안 썼을 분야를 동원한다. 출처: Felix Rieseberg, "How to be more ambitious" (2026-10).

## 절차

1. **명사 → 동사**: 산출물이 아니라 하는 일로 다시 쓴다.
   - 예: "분기 덱" → "바쁜 사람이 30분 안에 인과를 믿고 불확실한 상황에서 결정하게 만들기".
2. **팀 구성**: 이 일이 실패하면 안 된다면 누구를 모으는가? 분야 2–4개 + 반대편 검증(red team) 1개.
   - 예: 분석가·기자·편집자 + 공매도 투자자·포렌식 회계사.
3. 각 분야마다 **그 분야가 실제로 하는 일**(기법·도구) 한 줄. 그 직업처럼 *쓰지* 말고 그 직업이 *하는 일*을 한다.
   - 나쁨: "공매도 투자자처럼 써라" / 좋음: "공매도 투자자가 하듯 약점 가설을 세우고 반증 자료를 찾는다".
4. 사용자에게 채택할 기법을 고르게 한다 (AskUserQuestion, 복수 선택). 이미 정했으면 생략.

## 계획 반영 (`## Ambition` → Range)
- 동사 재서술 + 채택한 분야·기법 + red team 단계.
- 결과 확인은 외부 판정자로. 모델 자기 평가 금지.
- 해당 없음 (분야가 명확한 단순 작업) → `N/A — 이유`.

## 하지 않는 것
- 역할극 대화체, 페르소나 연기. transcript 만 이상해지고 결과는 나아지지 않는다.
