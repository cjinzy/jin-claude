# MCP Sequential-Thinking

Structured problem solving with explicit reasoning steps.

## When to Use
- Complex multi-step problems
- Architecture design decisions
- Debugging requiring systematic analysis
- When you need to show your reasoning process

## Key Commands
- `mcp__sequential_thinking__think`: Break down problem into steps

## Examples
```
# Analyze complex problem
Problem: "Design a scalable notification system"
Steps:
1. Define requirements (real-time, reliable, scalable)
2. Evaluate options (WebSockets, SSE, polling)
3. Consider trade-offs (latency vs. complexity)
4. Propose solution with justification
```

## Workflow
1. Define the problem clearly
2. Break down into sequential thinking steps
3. Show reasoning for each step
4. Arrive at conclusion with full rationale

## When NOT to Use
- Simple lookups or straightforward tasks
- When speed is more important than explicit reasoning
