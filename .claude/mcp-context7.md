# MCP Context7

Library documentation lookup and API reference.

## When to Use
- Before implementing unfamiliar library APIs
- Check latest documentation and examples
- Verify method signatures and parameters
- Understand library-specific patterns

## Key Commands
- `mcp__context7__search`: Search library documentation
- `mcp__context7__get`: Get specific documentation page

## Examples
```
mcp__context7__search("fastapi middleware")
mcp__context7__search("react hooks")
mcp__context7__get("fastapi", "tutorial/middleware")
```

## Workflow
Query Context7 before using unfamiliar libraries. If documentation is insufficient, use Context-mode to fetch external resources directly.
